# 英语小课桌 · 译林版 3-6 年级

一个**纯前端、零后端、可离线**的英语学习平台，专为小学生（译林版教材）打造，覆盖**听说读写**，主打**单词默写**。手机优先，可一键「添加到主屏幕」当 App 用。

🌐 在线地址：https://guoguo2009.github.io/english-desk/

---

## ✨ 功能特性

- **单词默写**（核心）：`看中文写英文` / `看英文写中文` / `🔊 听音默写` 三种模式，自动判分、记录错词。
- **单词库**：按单元浏览，点单词即发音，含音标与中文释义。
- **听力**：听发音选中文意思，即时反馈。
- **口语**：跟读打分（基于语音识别相似度）。
- **朗读**：单元单词逐个跟读，点词即读。
- **错词本**：写错的词自动收集，支持「只练错词本」专项巩固。
- **艾宾浩斯复习**：连续学习天数、单元掌握度可视化。
- **按年级总复习**：跨上 / 下册综合测验，可选模式与题量。
- **多册支持**：三年级 ~ 六年级，共 8 册、约 991 词，音标全部补齐。
- **PWA 离线**：支持离线使用，可安装到手机桌面。

---

## 🧱 技术栈

- 纯 HTML + CSS + 原生 JavaScript，**无框架、无构建步骤**。
- 数据内置在 `assets/data.js`（译林版 3-6 年级词汇）。
- 发音用浏览器 `SpeechSynthesis`（TTS），口语评分用 `Web Speech` 语音识别。
- 进度 / 错词本存在浏览器 `localStorage`，**不上传任何服务器**。
- 离线能力由 `service-worker.js` + `manifest.webmanifest`（PWA）提供。

## 🚀 本地运行

直接双击 `index.html` 即可打开；若浏览器对 `file://` 下的某些功能有限制，建议起一个本地静态服务器：

```bash
# 任选其一
python -m http.server 8080
# 然后访问 http://localhost:8080
```

> 注意：语音识别（口语打分）在部分浏览器需要 HTTPS 或 localhost 才可用，纯 `file://` 下可能不可用。

## 📲 安装到桌面（PWA）

1. **安卓 Chrome / Edge**：打开站点 → 地址栏右侧「安装」图标，或菜单 →「安装应用」。
2. **iPhone / iPad（Safari）**：打开站点 → 底部「分享」→「添加到主屏幕」。
3. 安装后即为独立图标，**离线也能打开默写**。

> 提示：网页发音在手机自带浏览器（Safari / Chrome）中最稳定；微信内置浏览器在 iOS 上可能读不出声，建议「添加到主屏幕」后用独立窗口打开。

---

## 🔒 数据隐私

所有学习记录（已学单词、错词本、连续天数）只保存在**你自己的浏览器本地**，不会上传。清除浏览器缓存会丢失记录。不同设备 / 不同浏览器之间数据不互通。
